# Changelog

## 1.0.0-rc.1

The current release candidate includes:

- Vue 3 `ThemeProvider` and `StyleProvider` components;
- `createStyles`, `createStaticStyles`, `createGlobalStyle`, and `createStylish`;
- Theme, token, Stylish, and responsive composables;
- Multi-instance, CSS variable, transformer, and SSR extraction utilities;
- Light/dark themes and provider-bound feedback instances for antdv-next.

Full release history will be mirrored from repository releases when versions are published.
